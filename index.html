LandCare AI - Land Analysis Platform

LandCare AI is a comprehensive multi-section web application designed for land analysis, offering a modern, user-friendly interface with sections for introduction, features, interactive exploration, future predictions, and calls to action. The platform requires user authentication to access analysis features and delivers detailed insights through multiple vegetation indices (NDVI, EVI, SAVI), land cover classification, slope analysis, comprehensive risk assessment, historical trends analysis, and advanced forecasting. It integrates statistical (ARIMA/SARIMA) and machine learning (Random Forest) models, powered by Google Earth Engine (GEE), Open-Meteo APIs, and ML pipelines for NDVI forecasting. A sophisticated caching system optimizes performance for repeated analyses, ensuring fast response times.

Technologies Used:

  • Backend: Python 3.8+, Flask 2.0+, statsmodels, earthengine-api, geemap, pandas, numpy, Supabase, JWT
  • Frontend: HTML, CSS, JavaScript, Leaflet.js, D3.js
  • Integrations: Google Earth Engine, Open-Meteo, ERA5
  • Database: Supabase

What I Learned / Achieved:

  • Integrated AI/ML models (GEE Random Forest for spatial predictions and ARIMA for time series)
  • Achieved comprehensive benchmarking and deployed to production
  • Demonstrated expertise in satellite data processing, ML forecasting, and full-stack development
  • Focused on environmental and agricultural applications
